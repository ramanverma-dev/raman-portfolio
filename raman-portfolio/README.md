# Raman Verma Portfolio (React + Vite)

    npm install
    npm run dev      # local preview
    npm run build    # production build in dist/

- Edit your details (email, GitHub, LinkedIn, resume path) at the top of `src/App.jsx`.
- Put your resume at `public/Raman_Verma_Resume.pdf` so "Download Resume" works.
- Project cards use icon previews. Replace with real screenshots and set real repo/live links in `PROJECTS`.
- Robot lives in `src/Robot.jsx`: eyes follow cursor, hover = happy + wave, click = surprise / love / wink, rapid clicks = dizzy, idle 15s = sleepy.
- Colors: CSS variables at the top of `src/styles.css`.
